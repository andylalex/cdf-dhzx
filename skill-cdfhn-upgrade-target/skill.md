## 一、背景与目标

### 1.1 业务背景

为提升中免会员活跃度、丰富会员权益体系，扩大千帆福利中心影响力与用户吸引力，拟升级千帆兑换中心为**中免权益商城**，即建设积分权益、积分商城能力并整合至千帆兑换中心。

核心变化：
- 兑换权益从仅支持"贝壳兑换"扩展到支持"积分兑换"、"积分+现金兑换"
- 兑换权益实体从线上虚拟商品扩展到线下门店权益、有税商户代金券、大会员券等
- 同步为门店及有税商户开放制券及券核销功能
- 福利中心服务对象从中免海南电商用户，扩展为全部中免会员

### 1.2 产品目标

1. 丰富千帆福利中心能力，提高中免权益商城的吸引力与使用率
2. 提高积分使用率与回收率
3. 线上为线下引流，带动门店、有税商户消费

### 1.3 目标用户

**C端用户：** 中免会员、千帆全量用户、免税店线下客群

**B端用户：** 中免海南电商运营、门店运营、品牌运营

## 二、术语定义

| 术语 | 定义 |
|------|------|
| 积分 | 指中免会员积分。除中免体系购物积分抵现外，一期新增积分消耗兑换权益的场景 |
| 福利值/贝壳 | 中免海南电商用户激励体系纽带。固化名称"贝壳"，海星吃贝壳。用户通过任务获取，消耗获取额外福利 |
| 千帆福利中心 | 中免海南电商用户激励体系简称，含福利活动、任务中心、兑换中心三大版块 |
| 中免权益商城 | 升级后整合千帆兑换中心+千帆积分商城能力，统一对客呈现 |
| 权益兑换方式 | 现状支持全贝壳兑换，一期扩展积分、积分+现金。暂不支持同时使用积分和贝壳 |

### 兑换权益实体分类

| 大类 | 子类 | 说明 | 本期范围 |
|------|------|------|---------|
| 实物商品 | 实物礼品 | 非线上商品，人工发货。正装、试用装、品牌周边、房券等 | 一期仅改造兑换流程调整 |
| 实物商品 | 线上商品 | 积分+现金兑换线上商品，融入商城主流程 | 本期不涉及 |
| 实物商品 | 线下商品 | 门店POS售卖商品 | 本期不涉及（可间接通过大会员券实现） |
| 实物商品 | 赠品 | 未来计划：贝壳+付邮费兑换 | 本期不涉及 |
| 非实物虚拟商品 | 本地服务 | 门店/经营场所有税商户的服务权益：美容SPA、彩妆造型、头发护理、酒水品鉴、贵宾廊等 | 二期 |
| 非实物虚拟商品 | 优惠券/电子券 | 门店兑换券、有税商户代金券、大会员券 | 一期（门店兑换券+有税商户代金券）；三期（大会员券） |
| 非实物虚拟商品 | 虚拟权益 | 抽奖次数、补签卡、限定皮肤、付费会员等 | 本期不涉及 |

## 三、分阶段实施计划

### 3.0 总体分三期

| 阶段 | 核心能力 | 关键词 |
|------|---------|--------|
| **一期** | 积分兑换券 + 积分+现金兑换 + 繁星APP核销 | 门店兑换券、有税商户代金券、虚拟商品创建、券核销、对账 |
| **二期** | 积分兑换门店服务 + 在线预约 + 0元订单展示 | 门店服务权益、分时段库存、预约、虚拟商品维护 |
| **三期** | 会员等级差异化 + 大会员券兑换 | 会员等级权益差异、积分+现金兑换大会员券、导购预约 |

### 3.1 一期版本详细方案

#### 千帆（C端）

- 福利中心前端整合优化，升级为中免权益商城
- 中免权益商城支持消耗积分兑换"门店兑换券权益"
- 支持"积分+现金"购买"有税商户代金券"权益
- 免税店门店支持展示/跳转中免权益商城门店内权益
- 支持电子券类型虚拟商品，购买后系统自动发券

#### 繁星（B端）

- 后台支持"门店兑换券"、"有税商户代金券"的制券和激活
- 后台支持"门店兑换券权益"、"有税商户代金券权益"的兑换规则维护
- 后台支持"门店兑换券权益"到店核销
- 现有商户端有税商户收款，支持"有税商户代金券"核销

#### 一期核心业务流程

**门店兑换券权益（全积分兑换）：**
1. 活动维护：门店制券 → 门店维护兑换规则 → 电商配置展示顺序 → 门店负责人审批激活
2. 权益兑换：用户浏览兑换中心 → 选择门店兑换券 → 确认兑换（消耗积分） → 兑换成功 → 系统自动发券
3. 权益核销：用户到店 → 出示券码 → 门店繁星后台扫码/输入核销

**有税商户代金券权益（积分+现金兑换）：**
1. 活动维护：门店制券 → 创建虚拟商品 → 关联优惠券 → 门店维护兑换规则 → 审批激活
2. 权益兑换：用户浏览兑换中心 → 选择代金券 → 结算（积分+0.01元固定现金） → 支付现金部分 → 兑换成功 → 系统自动发券
3. 权益核销：用户到商户消费 → 收款时出示券 → 积分和券同时核销（优先用券再用积分）

#### 一期关键规则

- 积分兑换场景需强制千帆平台实名（大会员实名为必须）
- 逆向规则：一旦兑换不支持退款退积分（无论券是否核销），特殊情况后台手动处理
- 有税商户收款：现金部分智科收款（代销），由智科与门店结算
- 积分和券可同时核销，优先用券再用积分
- 大会员券和商家券是否可叠加，商家券制券时在千帆券中心设置

### 3.2 二期版本详细方案

#### 千帆（C端）
- 中免权益商城支持消耗积分兑换"门店服务权益"、在线预约
- 我的订单展示0元订单（全贝壳/全积分兑换订单）

#### 繁星（B端）
- 商户端收款、账单功能迁移至繁星APP
- 繁星后台支持虚拟商品创建和维护
- 自动获取大会员"门店服务"活动数据并生成兑换奖品

#### 二期核心：门店服务权益
- 门店服务权益（美容SPA、彩妆造型等）需跟中免会员打通
- 支持预约、分时段库存
- 消耗全积分兑换，不同会员等级兑换比例不同
- 积分和次数不返还

### 3.3 三期版本详细方案

#### 千帆（C端）
- 中免权益商城支持按会员等级权益差异化
- 支持"门店服务权益"在线预约导购
- 支持积分+现金兑换"大会员券权益"（待定）

#### 繁星（B端）
- "门店服务"虚拟商品预约匹配导购能力
- 后台支持"门店服务"类型虚拟商品的兑换规则维护，并区分会员等级
- "门店服务权益"私域发放能力

## 四、目标功能架构（第二版 - 目标架构）

### 4.1 整体架构要点

第二版功能架构是升级目标，关键变化：

1. **去除"贝壳+现金"和"积分+现金"的混合支付**（一期简化为纯积分/纯贝壳 + 纯积分/积分+现金两种独立路径）
2. **支付统一为"贝壳支付 / 积分支付"**，现金部分通过积分+现金单独处理
3. **新增"商城"模块**在结算链路中（对接EOP企业运营管理平台）
4. **新增"券中心对接"**模块（第三方对接）
5. **新增"大会员系统"**对接（积分核销、券派发、券查询、券核销）

### 4.2 C端入口设计

**公域入口（4个）：**
- 入口1：【我的】页面 → 新增【兑换中心】入口 → 积分页签
- 入口2：【中免服务台】页面 → 会员服务分类 → 【兑换中心】入口 → 积分页签
- 入口3：【中免会员卡】页面 → 新增【兑换中心】入口 → 积分页签（第三方对接：中免会员卡升级项目）
- 入口4：【福利中心】页面 → 查看全部 → 兑换中心 → 贝壳页签

**私域入口（1个）：**
- 入口5：门店页面 → 进入门店兑换中心私域页面

### 4.3 兑换中心页面详细功能

- **贝壳明细** / **积分明细** 入口
- **门店列表下拉框**：岛内按距离排序，岛外按名称排序，私域默认当前门店
- **搜索功能**：标签搜索（后台配置，可滑动）+ 搜索框（按奖品名称）
- **商品列表**：排序规则待定
- **顶部区域配置**：星宝、TAB页签在千帆后台管理端配置
- **私域页面**：根据门店ID筛选对应商品，展示顶部样式

### 4.4 商品详情页功能

- 内容包括：奖品图片、奖品基本信息、兑换规则，奖品文描
- 内容在后台奖品池新增奖品功能中配置
- 积分兑换：兑换价格随会员等级不同而不同
- 兑换按钮文案：
  - 贝壳兑换：可兑换 → "立即兑换" / 不可兑换 → "您还差 XX 贝壳即可兑换"
  - 积分兑换：纯积分 → "立即兑换" / 积分+现金 → "立即购买"

### 4.5 结算页功能

- 积分+现金：现金需跟支付对接
- 积分结算对接大会员系统（评估现有接口是否满足）
- 贝壳兑换对接自研团队
- 兑换结算和权益兑换订单为**独立服务**
- 结算成功对接大会员系统给用户发券

### 4.6 订单功能

- 兑换结算和权益兑换订单独立服务，暂不对接订单中心
- 实物履约：现状平台方线下管理，优化点为升级订单履约功能
- 虚拟履约（券）：券展示需查询大会员服务（参考券包功能）
- 券核销：对接中科软，对接大会员查询券核销状态
- 虚拟商品信息对接繁星、朱雀

## 五、第三方系统对接

### 5.1 大会员系统对接需求

## 七、风险控制

### 用户侧
- by权益设置用户每日、每月可核销次数上限，避免用户套取积分
- 不需要by用户维度设置核销积分金额上限

### 商户侧
- 核销环节要求商户上传消费小票，避免积分和代金券账单对不上
- 消费小票明细建议增加实付金额

## 十、订单类型分类

### 按订单内商品类型
- 实物商品订单
- 虚拟商品订单

### 按订单来源
- 常规订单（从常规黄金流程下单支付，不支持0元）
- 兑换订单（从权益商城兑换/抽奖获得兑换资格，支持0元）

### 兑换订单细分

| 类型 | 说明 |
|------|------|
| 全积分/全贝壳抵扣 0元订单 | 无需额外支付 |
| 积分/贝壳抵扣部分金额 | 仍需现金支付的兑换订单（本期不包含实物，未来拓展） |
| 优先使用积分/贝壳全额抵扣 | 不足的差额由现金支付（本期不包含，未来拓展） |
