## 1. 导航结构

整个后台为一级导航组「兑换管理」，下含 5 个二级菜单：

| 菜单名称  | panel ID          | 说明               |
| ----- | ----------------- | ---------------- |
| 奖品仓库  | `products`        | 奖品商品的管理          |
| 活动管理  | `activities`      | 兑换/抽奖活动的创建与管理    |
| 页面运营  | `exchangeCenter`  | 兑换中心前端页面的奖品上架与配置 |
| 兑换订单  | `orders`          | 用户兑换订单与退款管理      |
| 兑换对账单 | `reconciliation2` | 收入账单 + 成本账单      |

## 2. 奖品仓库模块

### 2.1 数据模型：`allProducts` 数组

| 字段               | 类型             | 说明           | 示例值                                                                             |
| ---------------- | -------------- | ------------ | ------------------------------------------------------------------------------- |
| `id`             | Number         | 自增ID         | `1`                                                                             |
| `prizeId`        | String         | 奖品编号         | `'PRIZE-0001'`                                                                  |
| `name`           | String         | 奖品名称         | `'雅诗兰黛持妆粉底液 30ml'`                                                              |
| `desc`           | String         | 奖品描述         | `'到店兑换券'`                                                                       |
| `sku`            | String         | SKU编码        | `'EX-CDF-001'`                                                                  |
| `category`       | String         | 奖品分类         | `'香水化妆品'` / `'电子券'` / `'虚拟权益'`                                                  |
| `tag`            | String         | 标签（同分类）      | `'香水化妆品'`                                                                       |
| `type`           | String         | 实物/虚拟        | `'实物'` / `'虚拟'`                                                                 |
| `original`       | Number         | 奖品价值         | `880`                                                                           |
| `cost`           | Number         | 奖品成本         | `440`                                                                           |
| `img`            | String         | 图片路径         | `'assets/product-1.jpg'`                                                        |
| `channel`        | String         | 适用门店         | `'三亚国际免税城'` / `'海口国际免税城'` / `'博鳌免税店'` / `'三亚凤凰机场店'` / `'海口美兰机场店'` / `'cdf中免海南'` |
| `relatedPrize`   | String         | 关联奖品名称       | `'夏日狂欢预约抽奖活动'`                                                                  |
| `relatedPrizeId` | String         | 关联奖品ID       | `'PRIZE-0002'`                                                                  |
| `stock`          | Number         | 可用库存（-1表示不限） | `25` / `-1`                                                                     |
| `totalStock`     | Number         | 总库存（-1表示不限）  | `100` / `-1`                                                                    |
| `deadlineType`   | String         | 有效期类型        | `'days'`（按天数） / `'date'`（按日期）                                                   |
| `deadlineValue`  | Number\|String | 有效期值         | `30` / `'2026-12-31'` / `-1`（不限）                                                |
| `status`         | String         | 状态           | `'启用'` / `'停用'`                                                                 |
| `prizeType`      | String         | 奖品类型         | `'实物礼品'` / `'优惠券-优选单券'` / `'优惠券-券中心'` / `'预约抽奖'` / `'转盘抽奖'` / `'福利值'`           |
| `usageScene`     | Array\<String> | 使用场景         | `['兑换中心', '转盘抽奖', '签到', '任务']`                                                  |
| `exchangeRule`   | String         | 兑换规则说明       | `'到店出示兑换码即可领取'`                                                                 |
| `createdBy`      | String         | 创建人          | `'运营专员A'`                                                                       |
| `createdAt`      | String         | 创建时间         | `'2026-07-18 14:30'`                                                            |

### 2.2 奖品类型枚举

新增/编辑弹窗中的可选类型：

| 奖品类型     | 说明            | 关联奖品是否必填 |
| -------- | ------------- | -------- |
| 优惠券-优选单券 | 优选单券类优惠券      | 是        |
| 优惠券-券中心  | 券中心类优惠券       | 是        |
| 实物礼品     | 实物奖品，需物流      | 否（可选）    |
| 预约抽奖     | 预约抽奖类奖品       | 是        |
| 转盘抽奖     | 转盘抽奖类奖品（历史数据） | -        |
| 福利值      | 福利值（历史数据保留）   | 禁用       |

| 表单字段  | 元素ID                                     | 类型            | 说明                                                              |
| ----- | ---------------------------------------- | ------------- | --------------------------------------------------------------- |
| 奖品名称  | `f_name`                                 | input         | 必填                                                              |
| 奖品描述  | `f_desc`                                 | input         | 选填                                                              |

| 可用库存  | `f_stock`                                | input(number) | -1为不限                                                           |
| 总库存   | `f_totalStock`                           | input(number) | -1为不限                                                           |
| 有效期   | `f_deadlineType` + `f_deadlineValue`     | radio + input | 按天数/按日期                                                         |
| 使用场景  | `f_usageScene`                           | checkbox多选    | 兑换中心/签到/任务/转盘抽奖                                                 |
| 状态    | `f_status`                               | select        | 启用/停用                                                           |
| 兑换规则  | `f_exchangeRule`                         | textarea      | 兑换规则说明                                                          |

操作类型枚举：

| 操作类型 | 说明     |
| ---- | ------ |
| 创建   | 新建奖品   |
| 编辑   | 修改奖品信息 |

| 停用   | 停用奖品   |
| 库存调整 | 修改库存   |

## 3. 活动管理模块

### 3.1 数据模型：`allActivities` 数组

| 字段               | 类型             | 说明     | 示例值                                                                                       |
| ---------------- | -------------- | ------ | ----------------------------------------------------------------------------------------- |
| `id`             | Number         | 活动ID   | `1`                                                                                       |
| `name`           | String         | 活动名称   | `'夏日狂欢兑换活动'`                                                                              |
| `platform`       | String         | 平台     | `'千帆'` / `'繁星-三亚国际免税城'` / `'繁星-海口国际免税城'` / `'繁星-博鳌免税店'` / `'繁星-三亚凤凰机场店'` / `'繁星-海口美兰机场店'` |
| `timeRange`      | Object         | 活动时间范围 | `{ start: '2026-07-19 10:00', end: '2026-07-25 23:59' }`                                  |
| `createdAt`      | String         | 创建时间   | `'2026-07-18 14:30'`                                                                      |
| `createdBy`      | String         | 创建人    | `'管理员'` / `'运营专员'`                                                                        |
| `status`         | String         | 活动状态   | `'pending'`（待审核） / `'active'`（进行中） / `'terminated'`（已终止）                                  |
| `rule`           | String         | 活动规则   | `'每人每场限兑2件'`                                                                              |
| `channel`        | Array\<String> | 投放渠道   | `['APP', '微信小程序']`                                                                        |
| `payType`        | String         | 支付方式   | `'积分'` / `'贝壳'`                                                                           |
| `memberDiscount` | Object         | 会员折扣   | `{ normal: 100, silver: 95, gold: 90, platinum: 85, diamond: 80 }`                        |
| `accountType`    | String         | 记账方式   | `'主营业务'` / `'非主营业务'`                                                                      |
| `budgetLimit`    | Number         | 预算上限   | `500000`                                                                                  |
| `actualCost`     | Number         | 实际成本   | `149600`                                                                                  |
| `actualRevenue`  | Number         | 实际收入   | `149600`                                                                                  |
| `items`          | Array\<Object> | 奖品配置列表 | 见下方奖品配置模型                                                                                 |
| `auditLogs`      | Array\<Object> | 审核日志   | 见下方审核日志模型                                                                                 |

### 3.2 奖品配置模型（`items` 数组）

| 字段           | 类型             | 说明                  | 示例值                                   |
| ------------ | -------------- | ------------------- | ------------------------------------- |
| `name`       | String         | 奖品名称                | `'雅诗兰黛粉底液 30ml'`                      |
| `type`       | String         | 奖品类型                | `'实物礼品'` / `'优惠券-优选单券'` / `'优惠券-券中心'` |
| `price`      | Number         | 兑换价格（分值）            | `8800`                                |
| `stock`      | Number         | 可用库存（-1为不限，显示为「不限」） | `50` / `-1`                           |
| `exchanged`  | Number         | 已兑换数量               | `12`                                  |
| `monthLimit` | Number         | 月限（-1为不限）           | `-1`                                  |
| `dayLimit`   | Number         | 日限（-1为不限）           | `-1`                                  |
| `tags`       | Array\<String> | 标签                  | `['限时', '会员专属']`                      |

### 3.3 奖品标签选择器

奖品配置中的标签字段使用**下拉搜索多选组件**：

| 属性   | 说明                               |
| ---- | -------------------------------- |
| 组件类型 | 下拉搜索多选                           |
| 搜索功能 | 输入关键词实时过滤标签选项                    |
| 展示规则 | 已选标签显示前2个 + 剩余数量（如「限时, 会员专属 +3」） |
| 交互   | 勾选后实时更新显示；点击外部自动关闭下拉面板           |
| 数据源  | `activityTags` 全局标签数组            |

### 3.4 会员折扣模型

## 4. 页面运营模块

### 4.1 模块结构

页面运营模块（`panel-exchangeCenter`）包含 3 个 Tab：

| Tab 名称 | Tab ID            | 说明          |
| ------ | ----------------- | ----------- |
| 积分奖品   | `centerTabPrizes` | 积分兑换的奖品上架管理 |
| 贝壳奖品   | `centerTabShells` | 贝壳兑换的奖品上架管理 |
| 页面配置   | `centerTabConfig` | 兑换中心页面配置    |

### 4.2 数据来源

页面运营的奖品数据来源于 `allProducts`，通过筛选 `payType`（积分/贝壳）区分。上架状态、排序、标签等通过前端状态管理。

### 4.3 积分兑换 Tab 表头字段

| 列名      | 对应字段                                          | 说明                 |
| ------- | --------------------------------------------- | ------------------ |
| 奖品名称    | `name` + `prizeType`                          | 奖品名称 + 类型副标题       |
| 奖品类型    | `prizeType`                                   | 类型badge            |
| 来源      | `platform` + `channel` + `sourceActivityName` | 平台 + 门店 + 活动名称组合展示 |
| 适用门店    | `channel`                                     | 门店名称               |
| 支付方式    | `payType`                                     | 积分（固定）             |
| 兑换积分    | `price`                                       | 兑换所需积分             |
| 活动时间范围  | `timeRange`                                   | 活动起止时间             |
| 奖品标签    | `tags`                                        | 标签数组badge展示        |
| 剩余/活动库存 | `stock` / `activityStock`                     | 剩余库存 / 活动总库存       |
| 上架状态    | `shelfStatus`                                 | 已上架/已下架            |
| 操作      | -                                             | 上移/下移/上架或下架/编辑     |

### 6.12 积分/贝壳拆分统计

成本账单中，每笔成本按支付方式拆分为积分成本和贝壳成本：

| 字段                          | 计算方式                      | 说明          |
| --------------------------- | ------------------------- | ----------- |
| `pointsCost`                | `totalCost * pointsRatio` | 积分承担的成本     |
| `shellsCost`                | `totalCost * shellsRatio` | 贝壳承担的成本     |
| `pointsRatio + shellsRatio` | = 100%                    | 比例由订单支付方式决定 |

收入账单中，积分收入和贝壳收入分别统计，退款也分别统计：

| 指标    | 说明          |
| ----- | ----------- |
| 积分净收入 | 积分收入 - 积分退款 |
| 贝壳净收入 | 贝壳收入 - 贝壳退款 |
